How I work

From complaint to a tool people use

  1. ObserveSit with the person and watch the task, not the slide about the task.
  2. Find the real problemThe complaint is a symptom. Find the repeated step behind it.
  3. Test the toolsTry two or three AI options on real inputs before picking one.
  4. Ship smallThe simplest version that saves time on day one, deployed with a link.
  5. Document & measureA one-page guide, then check whether people still use it a week later.

vakeel · वकील

Environmental Hacks 2026 · solo

Environmental clearance filings run to hundreds of pages, and the people living next to a coal plant can't read them in time to object. vakeel reads the filing for them and links every claim to its page.

Left: tap a ✓ to see the quote on the real PDF page. Right: claims the verifier rejected are shown, not hidden.

Friction
On page 18 of one set of committee minutes, a 1,320 MW coal expansion skips its public hearing. Nobody affected would find that line in time.
Design call
Trust beats fluency. Every number needs a word-for-word quote and a page, and code checks it against the PDF. Answers come in English, Hindi and the state's language, and the app never shows a number that failed the check.

KLIP

Interaction & character design · Electron

A voice-driven AI companion that lives in the corner of your screen. Hold a key, ask about anything on screen, and a small glowing character glides over to point at the answer.

Design
A character with no mouth and two capsule eyes that blink, look around and react. Six emotional states (idle, listening, thinking, speaking, success, error) run on a state machine animated with Framer Motion, so the assistant feels alive without a chat window.
Tools tested
ClaudeGPT-5Gemini 2.5ElevenLabsSarvam BulbulGroq WhisperSarvam Saarika

All are swappable live, so the best engine for each language or task can be compared side by side.

Shipped
Windows, macOS and Linux installers built by CI, a custom push-to-talk shortcut, local-only chat history and encrypted key storage. The idea credits Farza's macOS app Clicky; KLIP is a from-scratch, cross-platform build.

PR Radar

Workflow integration · FalkorDB

Maintainers keep asking "who knows this file?" and "is this a duplicate?" PR Radar answers from a graph of who wrote, reviewed and touched what, and shows the path behind every answer.

Integration
It meets people where they already work. A GitHub Action comments on every new PR with what the graph found, and an MCP server exposes the same tools inside Claude.
Insight
"What if this maintainer leaves?" 625 of 780 files they touched would have no other human reviewer. Each file comes with its proof path.

First-month hypotheses

Where I'd start looking at Ather

These are guesses until I talk to the designers. The job starts with listening. But these are friction points common to ID teams, and how I'd test each one quickly.

Industrial · Vehicle designSketch → render variations in minutes

Early concepts need many directions before one is worth a full render. Feed a line sketch to a guided image model and get 10 variants that keep the proportions.

Test: ControlNet / ComfyUI vs Vizcom on the team's own sketches

CMFColour & finish previews on real geometry

Trying a new colour or finish means a full re-render. A small tool that swaps CMF on a fixed render pass, using the team's swatch library, could cut that wait.

Test: render passes + material masks vs image-to-image recolour

Whole teamSearch the archive by image

"We did something like this in 2021" usually means digging through folders. Embed every past render and sketch so a designer can search by dropping in a picture.

Test: CLIP / SigLIP embeddings over a sample folder, measure search time

UI/UX · ReviewsDesign review → action list

Feedback said in a review gets lost. Record the review and turn it into tasks pinned to the frames it was about, in the tool the team already uses.

Built pieces already: speech → structure (PolyDeck, KLIP)

For each one: measure today's time, build the smallest version, ship it with a one-page guide, and keep it only if people use it in week two.
